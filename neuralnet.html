Deep Learning · From Scratch

A neural net, written by hand in JAX

No layers library, no optimizer package — explicit weight arrays, a forward pass written by hand, gradients from jax.grad, and Adam implemented from scratch. The model is a permutation-invariant attention network that learns to pool each five-player roster on its own. Its trained weights are shipped here and the forward pass is re-implemented in JavaScript, so you can watch it think and nudge the inputs live.
