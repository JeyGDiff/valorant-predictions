Methodology

how the model works

What it reads

The model looks at how each of the 10 players has been performing recently, then asks: based on current form, which roster is stronger? It was trained on ~32,000 professional matches going back to 2020.

Under the hood

A gradient-boosted classifier (XGBoost) with 587 features per match. Each player is described by rolling averages across their last 5, 10, and 20 matches plus career — ACS, KDA, KAST, first-blood rate, clutch rate, and more — then aggregated per roster and differenced across the two sides. A substitution-aware dual Elo system and pairwise roster-chemistry features layer on top.

An honest track record

Every past prediction used only data from before that match. The model trained on the oldest 80% of history, then predicted the remaining 20% in 200-match blocks, retraining after each — the same way it operates live. No look-ahead bias.

Refresh cadence

Predictions refresh hourly via GitHub Actions, resolving finished matches and picking up new upcoming ones. The model and training data are not publicly distributed.
