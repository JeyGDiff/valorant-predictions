About this model

A gradient-boosted classifier (XGBoost) trained on professional Valorant match history scraped from vlr.gg. Each player's form is summarised across rolling windows (last 5, 10, 20 matches and career) covering KDA, ACS, KAST, first-blood rate, and more. A match feature row is built by aggregating and differencing the two rosters' current stats — 587 features total.

The track record above uses a strict walk-forward backtest: the model never sees a match before predicting it. It trains on the earliest 80% of historical matches, then predicts the remaining 20% in blocks of 200, retraining after each block on all data seen so far. Accuracy and calibration are measured only on those holdout predictions.

Upcoming predictions use the full historical dataset as training data and are refreshed every 6 hours. The model and training data are not publicly distributed.
